# Muhammad Kamran | MERN Stack Developer Portfolio

A premium, modern portfolio built with React, Tailwind CSS v4, and Framer Motion.

## 🚀 Current Progress

- [x] **Modular Architecture**: Clean folder structure following Single Responsibility Principle.
- [x] **Hero Section**: Animated typography and SaaS-style call-to-actions.
- [x] **Skills Section**: Animated tech stack grid with interactive icons.
- [x] **Projects Section**: Glassmorphism cards showcasing EventPulse and mobile projects.

## 🛠️ Tech Stack

- **Frontend**: React (Vite), Tailwind CSS v4, Framer Motion
- **Icons**: React Icons, Lucide React
- **Deployment**: (Pending) Vercel

## 📁 Architecture

- `/components/sections`: Large page sections.
- `/components/ui`: Small reusable UI elements.
- `/constants`: Centralized data management for easy updates.
